# @orbitspatial/osls-core-wasm

WebAssembly build of osls-core — read and author OSLS speaker layouts in the browser or Node.

The pure-TypeScript engine ships as `@orbitspatial/osls-core` (`sdk/ts`); this is the future bit-exact C++→WASM build.

## Installation

```bash
npm install @orbitspatial/osls-core-wasm
```

## Usage

```javascript
import * as osls from '@orbitspatial/osls-core-wasm';

// Use the WASM engine
```

## Building

```bash
npm run build
```
